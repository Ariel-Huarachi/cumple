# 💖 Feliz Cumpleaños, Ana Laura

Un detalle animado para el cumpleaños de Ana Laura Guzmán: sobre sorpresa, corazón 3D que late, flor que florece, mensajes que se escriben solos y música de fondo.

## 📁 Archivos

```
cumple-ana-laura/
├── index.html   → estructura de la página
├── style.css    → diseño y animaciones (sobre, flor, tarjetas)
├── script.js    → corazón 3D, fondo, mensajes, música
├── musica.mp3   → (opcional) tu canción de fondo
└── README.md
```

## 🎵 Música
- Pon una canción en la carpeta con el nombre **`musica.mp3`** y sonará al abrir el sobre.
- Si no pones ninguna, suena una **cajita musical de "Feliz Cumpleaños"** creada por el navegador.
- El botón ♪ de arriba a la derecha pausa o reanuda la música.

## ✏️ Cambiar los mensajes
Abre `script.js` y edita `MENSAJE_1` y `MENSAJE_2` al inicio del archivo.

## 🚀 Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `cumple-ana-laura`).
2. Sube todos los archivos (**Add file → Upload files**).
3. Ve a **Settings → Pages**.
4. En **Source** elige `Deploy from a branch`, rama `main` y carpeta `/ (root)`. Guarda.
5. En 1–2 minutos tendrás el link: `https://TU-USUARIO.github.io/cumple-ana-laura/`

¡Mándale el link y que lo disfrute! 🎂
